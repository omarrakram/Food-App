# Official imagery goes here

Nothing in this folder is committed with the concept: the build environment
could not reach be-indie.com, its Shopify CDN or Instagram, and nothing was
substituted from elsewhere.

Name each file after its slot (any of .jpg .jpeg .png .webp .avif). A filled
slot replaces its procedural wash study on the site and in `/showcase`.

| slot | wants |
| --- | --- |
| `hero` | Campaign photograph, portrait, full-bleed. Denim-led look. |
| `scanner` | Full-length model in denim, portrait, plain background. |
| `scanner-detail` | Macro of the same garment's fabric (scanner loupe). |
| `product-destiny-black` | Destiny Black Jeans |
| `product-destiny-sponge` | Destiny Sponge Jeans |
| `product-wide-leg-midnight` | Wide Leg Midnight Blue |
| `product-indie-fit` | Indie Fit Jeans Blue Wash |
| `product-be-fluffy` | Be-Fluffy 2.0 Cloud Wash (showing the fringe) |
| `product-relaxed-grey` | Relaxed Mens Jeans Grey |
| `collage` | One look, portrait — duplicated through print treatments |
| `detail` | Close-up of denim: seam, stitching or wash detail |
| `end` | Closing campaign photograph, portrait |
| `logo` | The official BE-INDIE wordmark (.svg preferred) |

Focal points for cropping live in `src/brand/assets.ts` (`focus`).
